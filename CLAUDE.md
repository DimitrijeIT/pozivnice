# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Summary

DigiPoz is a Serbian wedding invitation platform. Couples fill a Google Form, which triggers automated preview generation (10 themes), theme selection, final site publishing, and guest RSVP tracking — all via Google Apps Script webhooks, GitHub Actions, and GitHub Pages.

## Commands

```bash
npm run serve                # Dev server on port 3000, serves public/
npm run preview              # node scripts/generate-preview.js <slug>
npm run generate             # node scripts/generate-final.js <slug> <theme>
npm run layout               # node scripts/generate-layout-preview.js <layout> [slug]
npm run layout:all           # Generate all 19 layout previews
npm run layout:list          # List available 2026 layouts
npm run cleanup              # Remove expired previews (>24h)
npm run validate             # Validate config.js settings
npm run screenshots          # Generate theme screenshots (requires Playwright)
```

No test suite or linter is configured.

## Architecture

### Two Template Systems

**Original (2025):** Single `templates/base.html` shared by 10 themes. Themes differ only in CSS (`templates/themes/{theme}/style.css`). Generated by `generate-preview.js` and `generate-final.js`.

**2026 Layouts:** Standalone `templates/base-{layout}.html` files (19 layouts: aurora, botanical, cinema, concert, envelope, filmnoir, gazette, glass, kinetic, letter, magazine, mediterranean, oldmoney, passport, scribble, storybook, telegram, velvet, wabisabi) with completely different HTML structures. Each layout has themes in `templates/themes-{layout}/{theme}/`. Generated by `generate-layout-preview.js`.

### CSS Assembly

For the original system, `generate-final.js` concatenates CSS into two build-time replacements:

- `{{THEME_CSS}}` = `themes/{theme}/style.css` only
- `{{ANIMATIONS_CSS}}` = `animations.css` + `components.css` + `backgrounds.css` + `decorations.css` + `mobile.css`

Additional shared CSS files exist (`tokens.css`, `shared-forms.css`, `shared-sections.css`) but are not part of the `{{ANIMATIONS_CSS}}` bundle.

2026 standalone templates have their own inline `<style>` blocks. Their `{{THEME_CSS}}` is assembled from `tokens.css` + `mobile.css` + `themes-{layout}/{theme}/style.css`.

### Template Variable System

Implemented in `scripts/utils.js`:

- `{{VARIABLE}}` — HTML-escaped replacement. Fields ending in `_URL` or `_ISO` are not escaped.
- `{{#IF_CONDITION}}...{{/IF_CONDITION}}` — Conditional blocks. Shown when the matching data key is truthy.
- Raw HTML fields (no escaping): `THEME_CSS`, `ANIMATIONS_CSS`, `THEME_FONTS`, `CALENDAR_BUTTONS`, `TIMELINE_ITEMS`, `GALLERY_ITEMS`, `MEAL_OPTIONS`, `MEAL_OPTIONS_HTML`, `DRESS_CODE_COLOR_SWATCHES`, `_themeCss`, `_themeFonts`.

### Generation Pipeline

```
Original (2025):
data/{slug}.json → generate-preview.js → public/preview/{slug}/ (10 themed HTMLs + index.html)
                 → generate-final.js    → public/site/{slug}/    (single themed index.html)

2026 Layouts:
data/{slug}.json → generate-layout-preview.js → public/preview/{slug}/ (per-layout themed HTMLs + index.html)
```

`generate-preview.js` creates all 10 original theme variants plus a theme selector page. `generate-final.js` creates the permanent single-theme site and optionally deletes the preview. `generate-layout-preview.js` generates previews for 2026 layouts independently.

### Automation Flow

Google Apps Scripts in `google-apps-script/` bridge external services to GitHub:

1. `intake-form-handler-automated.gs` — Google Form submit triggers `repository_dispatch` → `generate-preview.yml`
2. `theme-selection-handler-automated.gs` — Theme selection POST triggers `repository_dispatch` → `generate-final.yml`
3. `rsvp-handler.gs` — Guest RSVP POST → looks up per-couple spreadsheet via `RSVP_Lookup` tab → writes to dedicated per-couple Google Spreadsheet
4. `rsvp-count-handler.gs` — GET endpoint returning live RSVP counts from per-couple spreadsheets

Legacy (non-automated) versions also exist: `intake-form-handler.gs`, `theme-selection-handler.gs`.

### Key Modules

- `scripts/config.js` — Theme/layout registry (`LAYOUT_REGISTRY` with `isOriginal` flag), Google Script URLs, domain config
- `scripts/utils.js` — Template processing (`replacePlaceholders`, `processConditionals`), Cyrillic-to-Latin `slugify`, date formatting, calendar link generation, data validation
- `scripts/generate-layout-preview.js` — Unified generator for all 19 2026 layouts (independent from original theme generators)
- `templates/script.js` — Client-side JS inlined into invitations (countdown, gallery lightbox, RSVP form, scroll animations, confetti)

## Conventions

- All user-facing text is in **Serbian Cyrillic**. Date formatting uses Serbian month/day names.
- Wedding data JSON uses snake_case keys (`bride_name`, `ceremony_venue`, `wedding_date`).
- Template placeholders use SCREAMING_SNAKE_CASE (`{{BRIDE_NAME}}`).
- Slugs are auto-generated from Cyrillic names via transliteration (`Ана-Марко` → `ana-marko`).
- The client-side `script.js` uses an IIFE with `'use strict'` and checks for demo mode by detecting unreplaced `{{RSVP_SCRIPT_URL}}` in the config.
- Output is fully self-contained single-file HTML (all CSS and JS inlined, no external dependencies except Google Fonts).

## Issues Found (Prioritized)

### P0 -- Blocking Issues

**1. Google Search Console not set up**
The #1 blocker. No amount of on-page optimization matters if Google doesn't know the site exists. Ownership needs to be verified and the sitemap submitted.

**2. Bing Webmaster Tools not set up**
Required for Microsoft Copilot and ChatGPT (which uses Bing's web index for browsing). Also enables IndexNow for instant indexing.

### P1 -- High Impact

**3. `cene.html` is an orphan page** [FIXED 2026-02-22]
Only linked from the homepage footer (line 1722). Not in main navigation, not linked from showcase.html. Search engines deprioritize pages with weak internal linking.

**Fix:** Add to main nav + link from showcase CTA section.

**4. Image alt texts are too generic** [FIXED 2026-02-22]
All 12 homepage images and 19 showcase images use single-word alt texts like `"Cinema"`, `"Passport"`, `"Glass"`. These miss keyword opportunities.

**Better:** `"Cinema дизајн дигиталне позивнице за венчање"` -- includes the target keyword naturally.

**5. Homepage logo links to `#` instead of `/`** [FIXED 2026-02-22]
`index.html` line 1232: `<a href="#">`. This is a dead link that wastes crawl equity. showcase.html already correctly uses `href="/"`.

**6. showcase.html has no JSON-LD** [FIXED 2026-02-22]
The showcase page is the second most important page but has zero structured data. Should have `ItemList` schema listing all designs.

**7. No blog or content pages**
Competitors have content strategies:
- brankomarkovic.com has blog posts about web design
- sajtzavencanje.rs has educational content ("What are electronic invitations?")

DigiPoz has 0 content pages targeting long-tail queries like:
- "kako napraviti digitalnu pozivnicu za vencanje"
- "prednosti digitalnih pozivnica"
- "ideje za pozivnice za vencanje 2026"

These are the queries AI search engines answer. Without content, there is nothing for them to cite.

### P2 -- Medium Impact

**8. No breadcrumb navigation on inner pages**
Competitors (sajtzavencanje.rs) have `BreadcrumbList` schema. Breadcrumbs improve both user navigation and rich snippets in search results.

**9. No contact/about page (E-E-A-T gap)**
Google's E-E-A-T (Experience, Expertise, Authoritativeness, Trustworthiness) scoring looks for:
- Who is behind this business?
- Contact information
- Physical address or at least a location

A simple "O nama" page with founder info, contact email, and Instagram would help.

**10. FAQ accordion missing `aria-expanded`** [FIXED 2026-02-22]
Homepage FAQ buttons lack `aria-expanded` and `aria-controls` attributes. This hurts accessibility scores, which Google uses as a ranking signal.

**11. Internal linking is thin** [FIXED 2026-02-22]
Cross-linking between all pages improves crawl depth and distributes page authority.

**12. Missing `hreflang` tag** [FIXED 2026-02-22]
While the site is Serbian-only, adding `<link rel="alternate" hreflang="sr" href="...">` explicitly signals language to search engines and avoids misclassification.

### P3 -- Low Impact / Nice-to-have

**13. URL structure could be more keyword-rich**
`/showcase.html` could be `/dizajni-pozivnica.html` (contains keywords). Not critical -- changing URLs now would require redirects.

**14. No `lastmod` automation in sitemap**
Sitemap dates are hardcoded to `2026-02-21`. Should auto-update when content changes.

**15. OG image is a logo, not a designed preview**
All pages use `digipoz_logo.png` as `og:image`. A designed 1200x630 social preview card would get significantly more engagement when shared on Viber/WhatsApp.

**16. No social proof signals for E-E-A-T**
Testimonials were added but have no schema markup (Review/AggregateRating). Adding review schema could unlock star ratings in search results.

## Google Search Console Setup (Manual)

1. Go to https://search.google.com/search-console
2. Add property `https://digipoz.rs`
3. Verify via DNS TXT record (add to domain registrar) or HTML file upload
4. Once verified, go to **Sitemaps** and submit `https://digipoz.rs/sitemap.xml`
5. Use **URL Inspection** to request indexing for `/`, `/showcase.html`, `/cene.html`

## Bing Webmaster Tools Setup (Manual)

1. Go to https://www.bing.com/webmasters
2. Add site `https://digipoz.rs`
3. Verify via DNS or CNAME
4. Submit sitemap `https://digipoz.rs/sitemap.xml`
5. Enable IndexNow for instant Bing/Copilot indexing on future changes

     │ Plan: Automate Instagram Post Creation & Publishing                                                                                                                                                           │
     │                                                                                                                                                                                                               │
     │ Context                                                                                                                                                                                                       │
     │                                                                                                                                                                                                               │
     │ DigiPoz already has a strong content generation pipeline — scripts that produce Instagram-ready assets (1080x1350 feed images, 1080x1920 reel videos) via Playwright + FFmpeg. The missing piece is the last  │
     │ mile: programmatically publishing those assets to Instagram without manual uploading.                                                                                                                         │
     │                                                                                                                                                                                                               │
     │ What Already Exists                                                                                                                                                                                           │
     │                                                                                                                                                                                                               │
     │ - scripts/generate-instagram-scroll-videos.js — Generates reel videos for all 19 layouts                                                                                                                      │
     │ - scripts/generate-instagram-10day-assets.js — Feed images + reel videos for 10-day campaigns                                                                                                                 │
     │ - scripts/reel-audio-tool.js — Audio processing for reels                                                                                                                                                     │
     │ - output/ — Generated assets ready for posting                                                                                                                                                                │
     │ - marketing/instagram-content-calendar.md — 30-day content plan with captions in Serbian                                                                                                                      │
     │ - docs/instagram-content-bank.md — Captions, hashtags, response templates                                                                                                                                     │
     │                                                                                                                                                                                                               │
     │ The Gap                                                                                                                                                                                                       │
     │                                                                                                                                                                                                               │
     │ No Meta API integration exists. All posting is currently manual.                                                                                                                                              │
     │                                                                                                                                                                                                               │
     │ ---                                                                                                                                                                                                           │
     │ Recommended Approach: Instagram Platform API (Direct Login)                                                                                                                                                   │
     │                                                                                                                                                                                                               │
     │ Why this over alternatives:                                                                                                                                                                                   │
     │ - Free forever — no recurring costs (Late API = $19/mo, Buffer/Hootsuite = more)                                                                                                                              │
     │ - No Facebook Page required — uses newer Instagram Platform API (launched July 2024) with direct Instagram login                                                                                              │
     │ - Self-publishing doesn't require full App Review — only needed for managing other users' accounts                                                                                                            │
     │ - DigiPoz already has Node.js infrastructure — fits naturally into existing scripts                                                                                                                           │
     │                                                                                                                                                                                                               │
     │ Prerequisites (Manual Steps — Cannot Be Automated by Code)                                                                                                                                                    │
     │                                                                                                                                                                                                               │
     │ 1. Ensure Instagram account is a Business (not Personal/Creator) account                                                                                                                                      │
     │ 2. Create a Meta Developer Account at developers.facebook.com                                                                                                                                                 │
     │ 3. Create a Business-type app and add the "Instagram" product                                                                                                                                                 │
     │ 4. Configure OAuth redirect URI (e.g., https://digipoz.rs/auth/callback)                                                                                                                                      │
     │ 5. Generate a long-lived access token for the DigiPoz Instagram account                                                                                                                                       │
     │ 6. Store the token securely (.env file, never committed to git)                                                                                                                                               │
     │                                                                                                                                                                                                               │
     │ Implementation Steps                                                                                                                                                                                          │
     │                                                                                                                                                                                                               │
     │ Step 1: Create scripts/publish-to-instagram.js                                                                                                                                                                │
     │                                                                                                                                                                                                               │
     │ A new Node.js script that:                                                                                                                                                                                    │
     │                                                                                                                                                                                                               │
     │ 1. Reads asset metadata — Takes arguments for media path, caption, and content type (image/reel/carousel)                                                                                                     │
     │ 2. Uploads media to a public URL — Since Instagram API requires HTTPS-accessible media URLs, the script will:                                                                                                 │
     │   - Option A: Use the existing digipoz.rs GitHub Pages domain (commit asset to public/assets/instagram/, push, use the URL)                                                                                   │
     │   - Option B: Upload to a temporary file host via API (e.g., Cloudflare R2, or imgbb for simplicity)                                                                                                          │
     │ 3. Creates a media container via Instagram Content Publishing API                                                                                                                                             │
     │ 4. Publishes the container (or schedules it with publish_time)                                                                                                                                                │
     │ 5. Logs result (post ID, URL, timestamp)                                                                                                                                                                      │
     │                                                                                                                                                                                                               │
     │ Usage:                                                                                                                                                                                                        │
     │   node scripts/publish-to-instagram.js post --image output/separate_posts/cinema.jpg --caption "..."                                                                                                          │
     │   node scripts/publish-to-instagram.js reel --video output/scroll_animations/cinema.mp4 --caption "..."                                                                                                       │
     │   node scripts/publish-to-instagram.js schedule --image ... --caption ... --time "2026-03-01T19:00:00+01:00"                                                                                                  │
     │                                                                                                                                                                                                               │
     │ Step 2: Create scripts/instagram-campaign.js                                                                                                                                                                  │
     │                                                                                                                                                                                                               │
     │ A campaign orchestrator that:                                                                                                                                                                                 │
     │                                                                                                                                                                                                               │
     │ 1. Reads a campaign definition file (JSON/YAML) specifying day-by-day content                                                                                                                                 │
     │ 2. Generates assets if not already generated (calls existing scripts)                                                                                                                                         │
     │ 3. Publishes or schedules each post via publish-to-instagram.js                                                                                                                                               │
     │ 4. Tracks what's been posted (avoids duplicates)                                                                                                                                                              │
     │                                                                                                                                                                                                               │
     │ Campaign file format (e.g., marketing/campaigns/10-day.json):                                                                                                                                                 │
     │ [                                                                                                                                                                                                             │
     │   {                                                                                                                                                                                                           │
     │     "day": 1,                                                                                                                                                                                                 │
     │     "type": "reel",                                                                                                                                                                                           │
     │     "asset": "output/scroll_animations_live/cinema.mp4",                                                                                                                                                      │
     │     "caption": "Cinema dizajn pozivnice...",                                                                                                                                                                  │
     │     "schedule": "2026-03-01T19:00:00+01:00"                                                                                                                                                                   │
     │   }                                                                                                                                                                                                           │
     │ ]                                                                                                                                                                                                             │
     │                                                                                                                                                                                                               │
     │ Step 3: Add npm scripts to package.json                                                                                                                                                                       │
     │                                                                                                                                                                                                               │
     │ "instagram:post": "node scripts/publish-to-instagram.js post",                                                                                                                                                │
     │ "instagram:reel": "node scripts/publish-to-instagram.js reel",                                                                                                                                                │
     │ "instagram:schedule": "node scripts/publish-to-instagram.js schedule",                                                                                                                                        │
     │ "instagram:campaign": "node scripts/instagram-campaign.js"                                                                                                                                                    │
     │                                                                                                                                                                                                               │
     │ Step 4: Token management utility                                                                                                                                                                              │
     │                                                                                                                                                                                                               │
     │ Add a helper command for token refresh (tokens expire every 60 days):                                                                                                                                         │
     │ "instagram:token-refresh": "node scripts/publish-to-instagram.js refresh-token"                                                                                                                               │

     │ ---                                                                                                                                                                                                           │
     │ Media Hosting Solution                                                                                                                                                                                        │
     │                                                                                                                                                                                                               │
     │ The Instagram API requires media at public HTTPS URLs. Simplest approach:                                                                                                                                     │
     │                                                                                                                                                                                                               │
     │ Use GitHub Pages (already deployed at digipoz.rs):                                                                                                                                                            │
     │ - Before publishing, copy the asset to public/assets/instagram/                                                                                                                                               │
     │ - Commit and push (or use GitHub API to upload)                                                                                                                                                               │
     │ - Reference as https://digipoz.rs/assets/instagram/filename.jpg                                                                                                                                               │
     │ - Clean up old assets periodically                                                                                                                                                                            │
     │                                                                                                                                                                                                               │
     │ Alternative (if push-before-post is too slow): Use imgbb free API (no account needed, 32MB limit, auto-expiring URLs) as a temporary host. The script uploads the local file, gets a URL, passes it to        │
     │ Instagram API.                                                                                                                                                                                                │

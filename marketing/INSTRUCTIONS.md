# Instagram Marketing Campaign — Digitalne Pozivnice
# Master Instructions & Campaign Guide

## Overview

This directory contains a complete Instagram marketing campaign for the Serbian digital wedding invitations product. The campaign targets the Serbian market with all content in Serbian (Latin script).

**Product:** Digital wedding invitations with 10 unique interactive layouts
**Market:** Serbia (Beograd, Novi Sad, Nis, Kragujevac)
**Target:** Women 23-35, engaged, urban, tech-savvy
**Language:** Serbian (Latin script)

## How to Use This Campaign

### Step 1: Set Up Instagram Account

1. Create Instagram Business account: `@digitalnepozivnice` (or your chosen handle)
2. Set up bio from `brand-voice-and-content.md` → Instagram Bio section
3. Create Highlight covers using prompts from `image-prompts.md` → Highlight Cover Set
4. Link website in bio (use Linktree or similar for multiple links)
5. Connect to Facebook Business Manager for ads

### Step 2: Generate Visual Assets

1. Open `image-prompts.md`
2. Generate images using Midjourney, DALL-E 3, or Ideogram
3. Priority images to generate first:
   - **Hero images for each layout** (prompts 1-10) — needed for launch week
   - **Highlight covers** (prompts 32-37) — needed for profile setup
   - **Ad creatives** (prompts 29-31) — needed for paid campaigns
4. After generating base images:
   - Composite real invitation screenshots onto phone screens
   - Add Serbian text overlays in Canva
   - Apply consistent warm color grading
   - Add subtle brand watermark
5. Export at correct sizes:
   - Feed posts: 1080x1350px (4:5)
   - Stories/Reels covers: 1080x1920px (9:16)
   - Carousels: 1080x1080px (1:1)

### Step 3: Prepare Content

1. Open `brand-voice-and-content.md`
2. Review brand voice guidelines — all team members should read this
3. Prepare first week of content:
   - Copy captions for posts 1-7
   - Prepare Reel 1 and Reel 2 scripts
   - Set up Story templates for week 1
4. Screen-record all 10 layouts on a phone for Reels footage
5. Create before/after comparisons (print vs digital)

### Step 4: Follow the Content Calendar

1. Open `instagram-content-calendar.md`
2. Follow the day-by-day posting schedule
3. Posting times (Serbian timezone, CET/CEST):
   - **Best times:** 11:00-13:00, 18:00-20:00
   - **Best days:** Tuesday, Wednesday, Thursday
   - **Reels:** Post during peak hours for maximum initial reach
4. Batch-create content weekly (every Sunday, prepare next week's posts)
5. Use scheduling tool (Later, Hootsuite, or Meta Business Suite)

### Step 5: Set Up Tracking

1. Open `campaign-tracking.md`
2. Set up UTM parameters for all links
3. Install Google Analytics on your website
4. Create tracking spreadsheet or dashboard
5. Set up weekly reporting cadence

### Step 6: Launch Paid Ads (Week 2+)

1. Wait until you have 10+ organic posts with engagement data
2. Start with best-performing organic content as ads
3. Budget allocation (from `campaign-tracking.md`):
   - **Phase 1 (Week 1-2):** €5-10/day — Awareness (Reach)
   - **Phase 2 (Week 3-4):** €10-15/day — Consideration (Traffic)
   - **Phase 3 (Month 2+):** €15-20/day — Conversion (Retargeting)
4. Use ad creatives from `image-prompts.md` (prompts 29-31)
5. Target: Women 23-35, Serbia, interests: wedding, engagement, bridal

### Step 7: Monitor & Optimize

1. Review `business-metrics.md` for KPI targets
2. Weekly check:
   - [ ] Engagement rate (target: >3%)
   - [ ] Reach growth
   - [ ] Profile visits → website clicks ratio
   - [ ] RSVP/preview conversions
   - [ ] Best performing content type
3. Monthly review:
   - [ ] Revenue vs projections
   - [ ] CAC (Customer Acquisition Cost)
   - [ ] Best layout showcases (which generates most interest)
   - [ ] Adjust content mix based on performance

## Campaign Timeline

### Pre-Launch (1 week before)
- [ ] Set up Instagram Business account
- [ ] Generate first batch of images (10 layout heroes + highlight covers)
- [ ] Prepare first 7 days of content
- [ ] Record screen captures of all 10 layouts
- [ ] Set up tracking (UTMs, Google Analytics)
- [ ] Create highlight covers and organize profile

### Week 1: Launch & Awareness
- [ ] Post daily following calendar
- [ ] Focus: introduce brand, show all 10 layouts
- [ ] Stories: 5-7 per day
- [ ] Engage: reply to every comment within 1 hour
- [ ] Target: 100 followers, 1000 reach per post

### Week 2: Feature Deep-Dive
- [ ] Showcase individual layouts in detail
- [ ] Start engagement content (polls, quizzes)
- [ ] Begin outreach to wedding influencers
- [ ] Consider launching first paid ad (awareness)
- [ ] Target: 300 followers, 2000 reach per post

### Week 3: Social Proof
- [ ] Share testimonials and reviews
- [ ] Post comparison content (print vs digital)
- [ ] Launch consideration ads (traffic to website)
- [ ] Partner content with 1-2 wedding accounts
- [ ] Target: 500 followers, 5000 reach per post

### Week 4: Conversion
- [ ] Promotional offers / launch discount
- [ ] Strong CTAs in every post
- [ ] Retargeting ads to website visitors
- [ ] FAQ and objection-handling content
- [ ] Target: 10 paid conversions, 700+ followers

### Month 2+: Scale
- [ ] Double down on what works (check analytics)
- [ ] Increase ad budget on winning creatives
- [ ] Monthly influencer collaborations
- [ ] User-generated content campaigns
- [ ] Seasonal adjustments (engagement season Dec-Feb, wedding season May-Oct)

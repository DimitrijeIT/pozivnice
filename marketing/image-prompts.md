## Notes on Usage

**Consistency tips:**
- Always include smartphone mockups showing actual invitation screenshots (composite real screenshots onto generated phone images)
- Maintain warm golden/blush color palette across all images
- Use consistent lighting style (golden hour / warm ambient)
- Add subtle brand watermark to all images before posting

**Editing workflow:**
1. Generate base image with AI
2. Composite real invitation screenshots onto phone screens in Figma/Photoshop
3. Add Serbian text overlays
4. Apply consistent color grading (warm, golden, slightly desaturated)
5. Add subtle brand element (small logo corner)
6. Export at 1080x1350 (4:5) for feed, 1080x1920 (9:16) for stories

**Tools recommended:**
- Midjourney v6 — best for photorealistic lifestyle/product shots
- DALL-E 3 — best for conceptual/comparison images
- Ideogram — best for images that need readable text
- Canva — for adding text overlays and branding
- Figma — for phone screen compositing

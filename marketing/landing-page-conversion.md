## 2. Pricing Strategy for Serbian Market

**Traditional Paper Invitations (Serbia)**
- Cost per invitation: 100-300 RSD
- Average wedding: 100-150 guests
- Total cost: 10,000-45,000 RSD
- Additional costs: Shipping (2,000-5,000 RSD), design changes (impossible/expensive)

Position as premium but affordable alternative (70-80% savings vs paper)

3. **Decoy Effect**: Basic tier makes Premium look like great value

4. **Bundle Pricing**: Premium Plus adds high-value bonuses at lower marginal cost

## 3. CTA Strategy

### Primary CTAs (High Contrast - #E91E63 Pink or #FF6B35 Orange)

**Above the Fold**
- Text: "Pogledajte Sve Dizajne"
- Placement: Hero section, centered, 60px height
- Psychology: Low commitment, curiosity-driven

**Pricing Section** (appears 3 times, once per tier)
- Text: "Izaberite [Tier Name] Paket"
- Placement: Bottom of each pricing card
- Psychology: Decision point, commitment

**Final CTA** (bottom of page)
- Text: "Kreirajte Svoju Pozivnicu Sada"
- Placement: Full-width section before footer
- Psychology: Urgency, action-oriented

### Secondary CTAs (Subtle - Outline Style)

**Navigation Bar**
- Text: "Kontaktirajte Nas"
- Placement: Top right corner
- Purpose: Lower friction for questions

**Preview Gallery**
- Text: "Pogledaj Demo" (on each layout)
- Purpose: Engagement, exploration

**Email Capture** (throughout page)
- Text: "Pošaljite Mi Primere" or "Dobij 500 RSD Popust"
- Placement: Exit intent popup, between sections
- Purpose: Lead generation for nurture campaign

### Urgency Triggers

1. **Scarcity** (use carefully, must be genuine)
   - "Samo 5 Premium paketa dostupno ove nedelje po ovoj ceni"
   - "15 parova je rezervisalo ovaj mesec"

2. **Time-Based** (seasonal)
   - "Venčavanje za manje od 3 meseca? Dobijate prioritetnu isporuku"
   - "Rezervišite do 15. maja i dobijte 15% popusta" (early bird wedding season)

3. **Social Proof**
   - "23 para je izabralo ovaj dizajn ovog meseca"
   - "Jelena iz Beograda je upravo naručila Premium paket"

4. **Fear of Missing Out (FOMO)**
   - "Sledeća cena važi od 1. maja" (before wedding season)
   - "Limitirana ponuda za prvih 50 klijenata"

### CTA Copy Variations (A/B Test)

**Action-Oriented**
- "Kreirajte Pozivnicu" vs "Započnite Sada"
- "Izaberite Dizajn" vs "Pogledajte Primere"

**Benefit-Oriented**
- "Uštedite 20,000 RSD" vs "Pošaljite Pozivnice za 5 Minuta"

**Risk-Reversal**
- "Probajte Bez Rizika - 30 Dana Garancija"

## 5. Mobile-First Considerations

### Critical Mobile Optimizations (95% Instagram Traffic)

**1. Mobile Page Speed** (Target: <2 seconds load time)
```
- Compress images: WebP format, lazy loading
- Minimize JavaScript: Defer non-critical scripts
- Use CDN: Cloudflare for static assets
- Critical CSS inline: Above-fold styles loaded first
- Font optimization: Subset fonts, woff2 format
```

**2. Mobile Navigation**
```
- Hamburger menu (top left)
- Sticky CTA button (bottom of screen, always visible)
- "Call" and "WhatsApp" buttons in menu
- One-tap actions: Click to call, click to message
```

**3. Mobile Hero Section**
```
Layout (320px-428px width):
┌─────────────────────────┐
│   [Logo]    [Menu ≡]    │
├─────────────────────────┤
│                         │
│  Moderne Digitalne      │

│                         │

│                         │
│  [Animated Preview]     │
│  (auto-play, 3 sec)     │
│                         │

│  (full-width button)    │
│                         │
│  Od 2,990 RSD           │
│                         │
└─────────────────────────┘
```

**4. Touch-Optimized Elements**
```
- Buttons: Minimum 44x44px (Apple guideline)
- Spacing: 16px minimum between tappable elements
- Forms: Large input fields (min 48px height)
- Dropdowns: Native mobile selectors
- Swipeable galleries: Horizontal scroll for layouts
```

**5. Mobile Form Optimization**
```
Contact/Checkout Form:
- Autofill enabled: name, email, phone
- Input types: type="tel" for phone, type="email"
- Minimal fields: Only ask what's necessary
- Inline validation: Real-time error messages
- Progress indicator: "Korak 1 od 3"
- Sticky "Nastavi" button at bottom
```

**6. Mobile Content Hierarchy**
```
- Shorter paragraphs: 2-3 sentences max
- Larger font sizes: 16px minimum (prevent zoom)
- High contrast: Dark text on light background
- Expandable sections: Accordions for FAQ, features
- Video autoplay muted: User controls available
```

**7. Mobile-Specific CTAs**
```
Primary CTA Styles:
- Fixed bottom bar (sticky): "Pogledaj Dizajne" + WhatsApp icon
- Full-width buttons: Edge-to-edge tappable area
- High contrast: Bright color (#E91E63) with white text

Click-to-Action Buttons:
- "Pozovi Nas" (tel: link)
- "Pošalji WhatsApp" (wa.me link)
- "Pošalji Email" (mailto: link)
```

**8. Instagram-Specific Optimization**
```
- UTM tracking: Track Instagram bio, story, post links separately
- Deep linking: Open Instagram app when sharing
- Vertical video: 9:16 aspect ratio for layout previews
- Stories-ready: Content snippets sized for IG stories (1080x1920)
```

**9. Mobile Loading States**
```
- Skeleton screens: Show layout structure while loading
- Progressive image loading: Low-res → high-res
- "Loading" indicators: On button clicks
- Offline messaging: "Proverite internet konekciju"
```

**10. Mobile Performance Budget**
```
Maximum per page:
- Total page size: 1.5MB
- Images: 800KB (compressed, responsive srcset)
- JavaScript: 300KB
- CSS: 100KB
- Fonts: 150KB
- Third-party scripts: 150KB (analytics, chat widget)
```

### Mobile Testing Checklist
```
✓ Test on real devices: iPhone 12/13/14, Samsung Galaxy S21/S22
✓ Portrait and landscape orientation
✓ Slow 3G network simulation (Chrome DevTools)
✓ Touch target sizes (no mis-taps)
✓ Form completion on mobile (keyboard doesn't hide CTA)

## 6. Conversion Funnel Optimization

```

```

### Funnel Optimization Framework

**Traffic Temperature Segmentation**
```
COLD Traffic (Instagram discovery, ads)
→ Landing page focus: Education + Visual appeal
→ CTA: "Pogledaj Primere" (low commitment)

WARM Traffic (Engaged with content, clicked multiple times)
→ Landing page focus: Social proof + Features
→ CTA: "Pogledaj Cene" (medium commitment)

HOT Traffic (Visited pricing, abandoned cart)
→ Landing page focus: Urgency + Risk reversal
→ CTA: "Završi Narudžbinu - Dobij 10% Popust" (high commitment)
```

**Funnel Drop-off Points & Solutions**

| Stage | Expected Drop-off | Solution |

## 9. Payment Methods for Serbian Market

### Critical Payment Considerations (Serbia)

**Serbian Payment Behavior**
- Cash culture: 60-70% of transactions still cash/bank transfer
- Card adoption growing: Younger demographics (23-35) more card-friendly
- Distrust of online payments: Security concerns, fraud fear
- Preference for COD: Even for digital goods (if possible)

### Recommended Payment Stack

**TIER 1: Essential Payment Methods**

**1. Credit/Debit Cards (Domestic & International)**
```
Provider: Stripe or PayPal
Supported: Visa, Mastercard, Maestro, Dina (domestic)

Setup:
- Stripe Connect (easiest international + RSD support)
- Display: "Prihvatamo sve kartice - Visa, Mastercard, Maestro, Dina"
- Security: SSL certificate + PCI compliance (handled by Stripe)

Pros:
- Instant payment confirmation
- Professional checkout experience
- Automated invoicing

Cons:
- 2.9% + 2 RSD per transaction fee
- Some users distrust online card entry

Optimization:
- Show security badges: "Zaštićeno Stripe enkripcijom"
- Display card logos prominently
- One-click checkout (saved cards for returning customers)
```

**2. Bank Transfer (Direktna Uplata)**
```
Provider: Manual processing
Process:
1. Customer selects "Bank Transfer"
2. Receive order details + bank account info
3. Customer makes transfer via mobile banking app
4. Uploads proof of payment (screenshot)
5. Manual verification (you) → deliver product

Account details to provide:
- Recipient: [Your Business Name / Personal Name]
- Bank: [e.g., Raiffeisen Banka, UniCredit]
- Account number (IBAN): RS35...
- Reference: Order #[12345]

Pros:
- Zero payment processing fees
- Familiar to Serbian customers
- Works for those without cards

Cons:
- Manual verification required
- 1-24h delay for confirmation
- Requires trust (customer pays before receiving)

Optimization:
- Automated email with payment instructions
- Upload portal for proof of payment
- SMS notification when payment confirmed

```
Provider: PayPal
Supported: PayPal balance, cards via PayPal

- PayPal Business account
- One-click PayPal button

- Buyer protection (builds trust)

- International customers

- Display: "Plaćanje zaštićeno PayPal-om"

**TIER 2: Alternative Payment Methods (Growth Phase)**

**4. Payment on Delivery (Plaćanje Pouzecem) - Adapted for Digital**
```
Challenge: Digital product = no physical delivery

Process:
1. Customer places order (no upfront payment)
2. You create personalized preview (watermarked)

4. If approved, customer pays → you remove watermark + deliver final

Cons:
- More manual work
- Some may request unlimited revisions before paying
- Risk of time waste (no-shows)

Optimization:
- Limit: 1 preview revision before payment
- Clear terms: "Preview je watermarkovan, finale nakon uplate"
- Conversion rate boost: 15-25% vs card-only

### Tier 3: Growth & Retention Metrics (Monthly Monitoring)

**9. Customer Lifetime Value (LTV)**
```
Formula: Average revenue per customer × Purchase frequency × Lifespan

For one-time purchase business:
- Base LTV = AOV (e.g., 5,000 RSD)
- Add repeat purchases (upsells, referrals):
  - Thank You cards: 15% repurchase = +225 RSD
  - Referrals: 30% refer 1 friend, 10% commission = +150 RSD
- Total LTV: ~5,375 RSD

LTV:CAC Ratio
- Formula: LTV / CAC
- Target: >3:1 (healthy unit economics)
- Example: 5,375 RSD LTV / 2,000 RSD CAC = 2.69:1 (needs improvement)

Tracking: Spreadsheet model with assumptions
```

**10. Referral & Viral Metrics**
```
Referral Rate
- Formula: (Customers from referrals / Total customers) × 100
- Target: 20-30% (word-of-mouth indicator)

Viral Coefficient (K-factor)
- Formula: (Invitations sent × Conversion rate)
- Target: >1 (self-sustaining growth)
- Example: Each customer refers 2 friends, 15% convert = K = 0.3

Net Promoter Score (NPS)
- Survey: "Koliko biste preporučili DigiPoz prijatelju?" (0-10)
- Formula: % Promoters (9-10) - % Detractors (0-6)
- Target: >50 (excellent)

Tracking: Post-purchase email survey + manual calculation
```

## Summary & Next Steps

### Critical Success Factors

1. **Mobile-First Design**: 80%+ traffic will be mobile (Instagram)
2. **Trust Building**: New brand needs aggressive social proof strategy
3. **Pricing Psychology**: Premium tier (4,990 RSD) as "no-brainer" choice
4. **Payment Flexibility**: Offer bank transfer + "preview before payment"
5. **Seasonal Strategy**: Capture off-season with early bird, maximize peak season
6. **Metrics from Day 1**: Track CVR, CAC, AOV, funnel drop-offs religiously

### 30-Day Action Plan

**Week 1: Pre-Launch Setup**
- Install all tracking (GA4, Meta Pixel, Hotjar)
- Finalize landing page structure (use template above)
- Set up payment integrations (Stripe, bank transfer instructions)
- Create 3-5 beta tester invitations (friends/family)

**Week 2: Content & Social Proof**
- Shoot founder video (60 sec)
- Create Instagram content calendar (30 posts)
- Set up email automation (welcome, abandoned cart)
- Request beta tester testimonials

**Week 3: Launch & Optimize**
- Soft launch to email list + close network
- Monitor metrics daily, fix broken funnel stages
- A/B test hero CTA copy (2 variations)
- Respond to all inquiries within 2h

**Week 4: Scale & Iterate**
- Launch Instagram ads (500 RSD/day budget)
- Analyze first 10 customers (survey, identify patterns)
- Optimize worst-performing funnel stage
- Implement first pricing test (early bird offer)

### Key Questions to Validate with Data

1. **Which layout resonates most?** → Track preview clicks by layout
2. **Is pricing too high/low?** → Monitor cart abandonment rate
3. **Do trust signals work?** → A/B test with/without guarantees
4. **Is Instagram the right channel?** → Compare CVR by traffic source
5. **What's the biggest objection?** → Analyze FAQ clicks, live chat questions

---

**This strategy is designed to be iterative. Launch with assumptions, validate with data, optimize ruthlessly.**
